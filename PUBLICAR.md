# Publicar LectoAventura gratis

No se puede usar `www.lectoaventura.com` sin comprar o controlar ese dominio.

La forma gratis es publicar la carpeta como sitio estatico y usar una URL gratuita del proveedor, por ejemplo:

- Netlify: `https://lectoaventura.netlify.app`
- GitHub Pages: `https://tuusuario.github.io/lectoaventura`

## Opcion recomendada: Netlify

1. Entra a `https://app.netlify.com/drop`.
2. Arrastra el archivo `lectoaventura-web.zip` o la carpeta `lectoaventura`.
3. Netlify generara una URL publica.
4. En configuracion del sitio puedes cambiar el subdominio gratuito si esta disponible.

## Opcion GitHub Pages

1. Crea un repositorio publico llamado `lectoaventura`.
2. Sube `index.html`, `styles.css`, `app.js` y la carpeta `assets`.
3. En Settings > Pages, publica desde la rama principal.
4. La URL quedara como `https://tuusuario.github.io/lectoaventura`.
